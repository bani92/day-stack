# DayStack Task 6 검색·날짜별 타임라인 설계

## 결정 사항

검색어가 비어 있어도 전체 Daily Log를 날짜 내림차순 타임라인으로 보여준다. 검색창 아래에는 `키워드로 기록을 찾아보세요.` 안내를 표시하고, 입력 중에는 일치하는 기록만 갱신한다.

## 목표

- 사용자가 저장된 Daily Log를 키워드로 찾을 수 있다.
- 검색 결과를 날짜 흐름으로 읽고 원하는 날짜 기록으로 이동할 수 있다.
- 검색어 없음, 결과 없음, 저장된 기록 없음 상태를 구분해 안내한다.
- 기존 로컬 저장소와 Pinia adapter 경계를 유지한다.

## 범위

포함:

- 네 프롬프트 필드의 대소문자 무시 부분 문자열 검색
- 빈 검색어일 때 전체 기록 반환
- 날짜 내림차순 정렬
- 일치한 프롬프트명과 한두 줄 발췌 표시
- `/day/:date` 상세 화면 이동
- 검색 결과 없음과 기록 없음 상태
- 모바일·데스크톱 반응형 검색 화면

제외:

- 서버 검색, 전문 검색 인덱스, debounce
- 프롬프트별 필터 UI
- 검색 결과 페이지네이션
- 기록 데이터 모델 변경

## 구조

### 순수 검색 함수

`src/domain/search-logs.ts`에 `searchLogs(logs, query)`를 둔다.

- 검색 대상 순서는 `done → learned → blocked → next`다.
- 각 필드를 `trim()`한 검색어의 소문자와 비교한다.
- 빈 검색어는 모든 로그를 반환한다.
- 결과는 `date` 내림차순으로 정렬한다.
- 일치 필드는 `matchedFields`에 중복 없이 담는다.
- `excerpt`는 매칭된 첫 번째 필드의 내용을 trim하고 화면용 길이로 줄인다.

### 저장 데이터 조회

`ArchiveView`는 `useAppDailyLogStore` adapter만 사용한다. 진입 시 `loadAll()`을 호출하고, `store.logs`를 검색 함수에 전달한다. `localStorage`나 Repository 구현체를 화면에서 직접 import하지 않는다.

### 화면 컴포넌트

- `SearchField`: visible label을 가진 단일 검색 input. 입력값을 `v-model`로 관리한다.
- `TimelineList`: 검색 결과를 구분선 기반의 단일 세로 목록으로 표시한다. 카드 그리드는 사용하지 않는다.
- `EmptyState`: 검색어 없음/결과 없음/기록 없음 상황의 안내와 가능한 행동을 표시한다.
- `ArchiveView`: 검색 상태, store 로드 상태, 라우팅을 조합한다.

결과 항목은 날짜, 매칭된 프롬프트명, 발췌를 보여주며 전체 항목을 링크 또는 버튼으로 제공해 키보드로 `/day/:date`에 이동할 수 있게 한다.

## 상태와 오류

| 상태 | 표시 |
|---|---|
| 로드 중 | 검색 결과 영역에 로딩 안내 |
| 기록 있음 + 검색어 없음 | 전체 타임라인 + 검색 안내 |
| 기록 없음 | 기록을 시작할 수 있는 안내 |
| 검색 결과 없음 | 검색어를 바꾸거나 지우는 행동 |
| 저장소 로드 실패 | 오류 문구와 다시 불러오기 행동 |

검색어를 지우면 즉시 전체 타임라인으로 돌아간다. 검색 중 오류가 발생해도 기존 화면 구조와 검색 입력값은 유지한다.

## 접근성·디자인

- 화면에는 `header`, `nav`, `main`, 단일 `h1`을 유지한다.
- 검색 input에는 항상 visible label을 제공한다.
- 검색 결과 항목은 키보드 포커스와 44px 이상 클릭 영역을 갖는다.
- 결과 없음 안내는 색상만으로 의미를 전달하지 않는다.
- 기존 Quiet Journal 색상 토큰과 Timeline Stack의 구분선 구조를 사용한다.
- 큰 KPI 카드, 카드 그리드, 강한 그라디언트, 보라색 중심 스타일은 사용하지 않는다.

## 테스트 전략

### 순수 함수

- 대소문자 무시
- 네 필드 검색
- 부분 문자열
- 빈 검색어의 전체 목록
- 결과 없음

### 화면

- 진입 시 `loadAll()` 호출
- 빈 검색어에서 전체 타임라인 표시
- 입력 시 검색 결과 갱신
- 검색 결과 없음 안내와 검색어 초기화
- 결과 클릭 시 `/day/:date` 이동
- 로드 실패 안내와 입력 상태 유지
- visible label, keyboard link, landmark, 단일 h1
